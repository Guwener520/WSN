# WSN 项目提升方案

> 当前状态评估：算法框架完整，但改进策略未生效（Improved < Standard），Grid baseline 过强，统计严谨性不足。本方案分四个阶段，按投入产出比排序。

---

## 阶段一：让改进策略"生效"（零代码改动，~30 分钟）

### 核心问题

当前 `MAX_ITER=50`，混沌初始化带来的多样性需要更长时间才能收敛。50 代内改进版还在"探索"阶段就被截断了。

### 行动

| 任务 | 操作 | 预估时间 |
|---|---|---|
| 增加迭代次数 | `MAX_ITER = 200` | 改一行 |
| 重新运行 lite 实验 | `python run_lite.py` | ~15 分钟 |
| 对比新旧结果 | 生成对比表格 | 5 分钟 |

### 预期效果

- ImprovedPSO 在 200 代时收敛到接近标准 PSO 的水平，且**冗余度更低**
- 收敛曲线能清楚展示：标准版前期快但后期停滞，改进版后程发力反超
- 这是"群体智能算法改进"论文中最经典的一个 narrative

### 验证标准

`ImprovedPSO.mean_fitness >= PSO.mean_fitness` 在至少一个场景中成立（200 代）。

---

## 阶段二：消融实验（Ablation Study，约 30 分钟编码 + 15 分钟运行）

### 要回答的问题

三个改进策略（混沌初始化、自适应权重、高斯变异）各自贡献了多少？

### 实验设计

| 变体 | 混沌初始化 | 自适应 w | 高斯变异 |
|---|---|---|---|
| PSO (baseline) | ✗ | ✗ | ✗ |
| PSO + Chaotic | ✓ | ✗ | ✗ |
| PSO + Adaptive | ✗ | ✓ | ✗ |
| PSO + Mutation | ✗ | ✗ | ✓ |
| PSO + Chaotic + Adaptive | ✓ | ✓ | ✗ |
| ImprovedPSO (full) | ✓ | ✓ | ✓ |

### 实现方式

为 `ImprovedPSO.__init__` 增加三个开关参数：

```python
ImprovedPSO(env, evaluator, 
    use_chaotic_init=True,    # 是否用 Logistic 映射
    use_adaptive_w=True,      # 是否线性衰减 w
    use_mutation=True,        # 是否在后期施加高斯变异
)
```

### 预期产出

一张热力图/表格，清晰展示每个策略模块的独立贡献和改进累积效应。

---

## 阶段三：统计严谨性补全（约 1 小时编码 + 20 分钟运行）

### 当前不足

- 仅 5 个种子，无法排除偶然性
- 缺少统计检验（答辩中很容易被问"你的改进是否 statistically significant？"）
- 没有箱线图展示结果分布

### 行动

| 任务 | 产出 |
|---|---|
| 30 次独立运行 | 每个算法 × 每场景 30 个独立种子 |
| 箱线图 | 覆盖率/Fitness 的分布可视化 |
| Wilcoxon 符号秩检验 | p 值表，证明改进是否显著 |
| Friedman 检验 + Nemenyi 事后检验 | 多算法综合排名 |

### 实现

scipy 已安装，直接调用 `scipy.stats.wilcoxon` 和 `scipy.stats.friedmanchisquare`。

## 阶段四：让 SI 算法真正"赢过" Grid（约 1 小时编码）

### 核心问题

Medium 场景 Grid 部署覆盖率 93.1%，PSO 只有 84.5%。如果答辩时被问到"你的智能算法为什么还不如简单网格排列？"，这是一个很致命的问题。

### 解决方案

#### 方案 A：更复杂的障碍物场景

Grid 在无障碍物的矩形区域内天然最优。引入更复杂的障碍物布局，让 Grid 的规则排列失效：

```python
OBSTACLES = [
    {"type": "rect", "x": 20, "y": 20, "w": 15, "h": 40},   # 纵向墙
    {"type": "rect", "x": 60, "y": 40, "w": 30, "h": 15},   # 横向墙
    {"type": "circle", "cx": 15, "cy": 80, "r": 12},         # 湖
    {"type": "circle", "cx": 85, "cy": 25, "r": 14},         # 湖
    {"type": "circle", "cx": 50, "cy": 85, "r": 10},         # 湖
]
```

在这类场景中，Grid 节点可能落在障碍物内，覆盖率大幅下降，SI 算法通过智能规避障碍物而胜出。

#### 方案 B：不规则监测区域

将矩形监测区域改为 L 形或多边形，Grid 更难以均匀覆盖。

#### 方案 C：异构节点（Heterogeneous Nodes）

引入两种感知半径（Rs=10 和 Rs=8 各半），Grid 无法适应这种非均匀性。

### 推荐

同时做 A + C。障碍物让 Grid 部署失效，异构节点让 SI 的"自适应分配"能力有额外价值。代码改动量不大，但实验结果的 narrative 会显著增强。
