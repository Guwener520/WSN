# 基于改进群体智能算法的 WSN 覆盖优化研究 — 项目计划

## 1. 项目概述

- **项目周期**：8 周（可根据课程要求调整）
- **开发模式**：迭代式开发，模块化推进
- **交付形式**：Python 源码包 + 实验报告 + 可视化结果 + 演示 PPT

## 2. 阶段划分与里程碑


| 指标 | 计算方式 | 含义 |

| 平均适应度 | 30 次独立运行适应度均值 | 综合多目标性能 |
| 收敛迭代次数 | 适应度达到终值 95% 所需迭代数 | 收敛速度 |

## 5. 风险与应对

| 风险 | 概率 | 应对措施 |
|---|---|---|
| 高维搜索陷入局部最优 | 中 | 混沌初始化 + 自适应参数 + 变异策略（已集成） |
| 改进效果不显著 | 中 | 进行参数敏感性分析，调优改进策略参数 |
| 计算耗时过长 | 低 | 使用 `grid_resolution` 控制网格精度；降低种群规模可加速 |
| 可视化效果不理想 | 低 | 参考 TakwaKhelifi 项目图表风格，迭代优化 |
