# 基于改进群体智能算法的 WSN 覆盖优化研究 — 项目说明

## 1. 项目背景

无线传感器网络（Wireless Sensor Network, WSN）是由大量微型传感器节点组成的自组织网络，广泛应用于环境监测、战场侦察、智能家居、工业物联网等领域。在这些应用中，传感器节点的部署位置直接决定了网络的覆盖质量——覆盖盲区会导致关键信息丢失，而过度重叠则造成资源浪费。

传统的节点部署方式（随机抛撒、规则网格）难以兼顾覆盖率与资源效率。群体智能（Swarm Intelligence, SI）算法通过模拟自然界生物群体的协作行为，能够在复杂的高维搜索空间中自动发现高质量的节点布局方案，近年来已成为 WSN 覆盖优化的研究热点。

## 2. 研究目标

在给定的二维监测区域内，利用**改进的群体智能算法**自动优化 N 个传感器节点的部署位置，实现以下多目标优化：

| 目标 | 含义 | 优化方向 |
|---|---|---|
| 覆盖率最大化 | 减小监测盲区，确保区域被充分感知 | ↑ 越大越好 |
| 冗余度最小化 | 避免多节点重复覆盖同一区域，节约能量和通信资源 | ↓ 越小越好 |
| 连通性保障 | 确保节点之间能够可靠通信，避免孤立节点 | ↑ 越大越好 |

## 3. 技术路线

### 3.1 环境建模

- 将连续监测区域离散化为均匀网格（默认 $100 \times 100$，分辨率可配置）
- 采用**二元感知模型**（Binary Sensing Model）：若网格点到传感器节点的欧氏距离 $\leq R_s$（感知半径），则该点被覆盖；否则不覆盖
- 构建通信邻接矩阵：若两节点距离 $\leq R_c$（通信半径），则连通

### 3.2 适应度函数

多目标加权聚合为单一适应度值：

$$Fitness = w_1 \cdot CoverageRate + w_2 \cdot (1 - RedundancyRate) + w_3 \cdot ConnectivityRate$$

- $CoverageRate$：被至少一个节点覆盖的网格点占比
- $RedundancyRate$：每个被覆盖点上的平均冗余节点数 / 总节点数
- $ConnectivityRate$：可通信节点对占比
- 默认权重 $(w_1, w_2, w_3) = (0.5, 0.3, 0.2)$，可灵活调整

### 3.3 群体智能算法

| 算法 | 编码方式 | 核心机制 |
|---|---|---|
| **PSO**（粒子群优化） | 粒子 = 所有节点坐标展平向量 | 个体最优 + 全局最优引导搜索 |
| **GWO**（灰狼优化） | 灰狼 = 所有节点坐标展平向量 | $\alpha, \beta, \delta$ 三层级领导引导包围 |
| **WOA**（鲸鱼优化） | 鲸鱼 = 所有节点坐标展平向量 | 包围捕食 + 螺旋气泡网攻击 |

### 3.4 改进策略（课程项目创新点）

| 策略 | 位置 | 作用 |
|---|---|---|
| **混沌初始化** | 种群初始化阶段 | 使用 Logistic 映射替代均匀随机，提高初始种群多样性 |
| **自适应参数** | 迭代搜索阶段 | PSO 惯性权重线性衰减、GWO/WOA 收敛因子非线性衰减，平衡勘探与开发 |
| **高斯变异** | 迭代后期 | 对部分个体施加高斯扰动，帮助跳出局部最优 |

## 4. 系统架构

```
WSN Coverage Optimization System
│
├── wsn/environment.py        ← 网格化监测区域建模、二元感知模型、通信图
├── wsn/fitness.py            ← 多目标适应度函数评估器
├── wsn/algorithms/           ← 群体智能算法层
│   ├── _base.py                  SwarmOptimizer 抽象基类
│   ├── pso.py                    PSO + ImprovedPSO
│   ├── gwo.py                    GWO + ImprovedGWO
│   └── woa.py                    WOA + ImprovedWOA
├── wsn/improvements/         ← 改进策略层
│   ├── chaotic_init.py           Logistic 混沌映射初始化
│   ├── adaptive_params.py        自适应惯性权重 / 收敛因子
│   └── mutation.py               高斯变异 + Lévy 飞行
├── wsn/visualization/        ← 可视化层
│   ├── static_plots.py           部署散点图 + 覆盖热力图 + 收敛曲线
│   ├── dynamic_plots.py          优化过程 GIF 动画
│   └── interactive_dash.py       Plotly 交互式仪表盘
├── wsn/experiments/          ← 实验层
│   ├── baselines.py              随机部署 / 规则网格部署基准
│   └── runner.py                 多算法对比实验运行器
└── tests/                    ← 单元测试（12 个用例）
```
